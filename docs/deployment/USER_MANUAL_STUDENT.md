# User manual — Student (v1.0)

Read [USER_MANUAL_COMMON.md](USER_MANUAL_COMMON.md) first.

## 1. See your assignments — option `1`

```
4 | MATH101 | Essay 1 | deadline 2026-11-20T12:00:00Z | max 100 | your extension 2026-11-23T12:00:00Z
```

The first number is the **assignment ID**. Times are UTC (12:00Z = 14:00 in Maseru). If you have been given an extension, it is shown, and it is your real deadline.

## 2. Submit your work — option `9`

1. Save your work as a file on this computer (for example on a USB stick).
2. Choose `9`, enter the assignment ID, then the full path to the file, for example `E:\Essay1.pdf` or `/media/usb/Essay1.pdf`.
3. You see `Submission file stored and saved (submission ID N).` Write the ID down as your receipt.

| Rule | Detail |
|---|---|
| File types | PDF, DOC, DOCX, TXT, ZIP, PNG, JPG/JPEG |
| File size | 1 byte to 20 MiB |
| Time | Recorded by the system when you submit; you cannot set it |

The system keeps its own copy, so you can remove your USB stick afterwards.

## 3. Fix a mistake — resubmit

Submit again with option `9` **before the deadline** (or your extension). The newest version is the one marked. After the deadline you cannot resubmit (`Resubmission is only permitted before the applicable deadline`).

## 4. Late work

Late work is accepted, not rejected, but it loses marks (provisional rule):

| How late | Effect |
|---|---|
| Any time up to 24 hours after the deadline | −10% of the maximum mark |
| More than 24 h, up to 48 h | −20% |
| More than 48 h, up to 72 h | −30% |
| More than 3 days | Mark 0 |

If you have a good reason for needing more time, ask your lecturer for an extension **before** the deadline.

## 5. See your marks and feedback — option `13`

```
MATH101 | Essay 1 | 60/100 | Good structure; cite your sources.
```

You only see marks that your Head of Department has checked and released. Until then, the assignment does not appear here, even if your lecturer has marked it. You can only ever see your own results.
