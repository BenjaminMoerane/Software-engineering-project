# Build and Run Guide — CS4433 Moderated LMS

This guide describes how to build the C++17 console application from a fresh checkout. The project uses CMake, SQLite3, and OpenSSL Crypto.

## 1. Prerequisites

Install:

- A C++17-capable compiler (GCC 10+, Clang 12+, or a current Visual Studio C++ toolchain).
- CMake 3.20 or newer.
- SQLite3 development headers and library.
- OpenSSL development headers and Crypto library.
- Git, to clone or check out the repository.

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install -y build-essential cmake git libsqlite3-dev libssl-dev
```

Check versions:

```bash
g++ --version
cmake --version
git --version
```

### Windows

Install Visual Studio 2022 with the **Desktop development with C++** workload, CMake, and Git. Install SQLite3 and OpenSSL development packages using your approved package manager/toolchain (for example, vcpkg), and ensure CMake can locate their headers and libraries. If using vcpkg, configure CMake with the vcpkg toolchain file, for example:

```powershell
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=C:/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake
```

Replace the example path with the actual path on your machine. The dependencies must be installed for the selected architecture (x64 or x86).

## 2. Obtain the source

Clone the repository if a Git remote has been configured:

```bash
git clone <repository-url>
cd CS4433_Phase_4
```

If you received a source archive or Git bundle instead, extract or clone it, then change into the `CS4433_Phase_4` project directory containing `CMakeLists.txt`.

## 3. Configure and build (Release)

From the project root:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

For a Debug build:

```bash
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug --parallel
```

On a multi-configuration generator such as Visual Studio, select the configuration at build time:

```powershell
cmake -S . -B build
cmake --build build --config Release
```

## 4. Run automated tests

```bash
ctest --test-dir build --output-on-failure
```

For a Visual Studio multi-configuration build:

```powershell
ctest --test-dir build -C Release --output-on-failure
```

A passing test suite is useful evidence but does not by itself establish that every assignment requirement is complete. See `docs/IMPLEMENTATION_TRACEABILITY.csv`, `docs/PHASE4_DELIVERABLE_AUDIT.md`, and `docs/GATE2_BLOCKERS.md` for current status and known gaps.

## 5. Run the application

On Linux/macOS-like shells:

```bash
./build/lms_app school_lms.sqlite3
```

On Windows, run the generated executable from the build output directory and provide a database path, for example:

```powershell
.\build\Release\lms_app.exe school_lms.sqlite3
```

The application creates/initializes its database according to the included schema. On a new database with no users, it prompts for the initial Administrator account. Use a strong password and protect the database file and the machine where it is stored.

## 6. Database and input notes

- Deadlines are entered as UTC timestamps in `YYYY-MM-DDTHH:MM:SSZ` format.
- Submission timestamps are generated by the application.
- Submission content is currently stored as a reference/path string; the application does not yet manage uploaded file bytes.
- Password input is not masked in the current console interface. Use only in a trusted environment.
- The late-penalty policy and several other business decisions remain provisional pending formal Gate 2 decisions. Do not treat them as stakeholder-approved policy until the blockers are resolved.

## 7. Clean rebuild

To remove generated build files and configure from scratch:

```bash
cmake -E rm -rf build
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

If CMake cannot find SQLite3 or OpenSSL, confirm that the development packages are installed and that their include/library paths are available to CMake. Do not commit generated build directories or database files; `.gitignore` excludes these by default.
