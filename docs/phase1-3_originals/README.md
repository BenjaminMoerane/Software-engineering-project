# Phase 1–3 original deliverables

The documents and diagrams as submitted at the Phase 1–3 gates, before implementation. They are kept as the historical record of the design.

**Status.** Where these differ from the current figures in [`docs/diagrams/`](../diagrams/), the current figures are authoritative: they were redrawn from the code at v1.1.2 after the repository refactor (Phase 5) and CR1 (v1.1) changed the design. The differences are explained in the final report and in [`docs/maintenance/CR1_DESIGN_UPDATES.md`](../maintenance/CR1_DESIGN_UPDATES.md).

The original diagrams exist only as images, so each is wrapped in a `.drawio` file. The draw.io link opens it in the draw.io viewer (zoom and pan); it is a picture, not an editable diagram.
